01 · Brand

Three sensibilities, one feel.

If a single phrase had to capture Vigil, it's "glass over a dark control room." Surfaces are translucent, the chrome behind them is gridded and dimly lit, and accent color appears only on things that matter: status, headings, primary actions, live data.

Sensibility 01

SOC / NOC

Dense numeric readouts, mono digits, status chips, an always-on LIVE pulse, gridlined surfaces.

Sensibility 02

Editorial

Generous letter-spacing on small caps, restrained type scale, lots of negative space.

Sensibility 03

Holographic

Soft radial glows, gradient text, prismatic sheen, glassy panels with backdrop blur.

Voice & tone

  • Plain, technical, confident. "Live WebSocket streaming." Not "Power up your monitoring journey."
  • Numbers over adjectives. "~140 KB gzipped" beats "blazingly fast."
  • No exclamation marks. No emoji in product UI.
  • Operator-friendly. Copy assumes a reader who reads logs.
02 · Mark

The Vigil cube-stack.

An isometric V built from cubic blocks. The left arm is a single smooth prism; the right arm is a stack of three cubes with a 25° twist on the top block. Both arms meet on a cyan apex — the literal point of the V, and the brand's hero color.

Anatomy
  • Apex cube — cyan, the hero color and visual anchor.
  • Right base block — blue / indigo, the foundation.
  • Right middle block — purple, secondary highlight.
  • Right top block (twisted ~25°) — fuchsia → amber.
  • Smooth left arm — cyan → emerald gradient along its length.
  • Soft cyan→blue radial halo behind the mark.
  • White rim highlights at 22% opacity for bevel readability.

Signature drop-shadow

brand-mark.css 
filter: drop-shadow(0 6px 18px rgba(34, 211, 238, 0.35));
/* On hover: intensify */
filter: drop-shadow(0 8px 22px rgba(34, 211, 238, 0.55));
Do — keep the gradient stack. Use the cyan halo on darker surfaces. Maintain ≥1 apex-cube of clear space on every side.
Don't — recolor the mark to a single tint, drop it on busy photographic backgrounds, or render flat without the halo on pure-white surfaces.

06 · Elevation

Two shadow recipes.

Use them. Don't invent new ones. Soft glass for content panels; dark drama for hero / marketing surfaces.

soft glass
dark drama
drama + cyan rim

Soft glass (panels)

elevation.css 
/* Light mode */
box-shadow:
  0 1px 0 rgba(255, 255, 255, 0.9) inset,
  0 8px 24px -8px rgba(15, 23, 42, 0.18),
  0 24px 48px -16px rgba(15, 23, 42, 0.18);

/* Dark mode swaps inset highlight for a faint cyan glow */
box-shadow:
  0 1px 0 rgba(255, 255, 255, 0.04) inset,
  0 8px 24px -8px rgba(0, 0, 0, 0.55),
  0 28px 56px -18px rgba(0, 0, 0, 0.6),
  0 0 0 1px rgba(96, 165, 250, 0.05);

07 · Atmosphere

Three layers behind everything.

11 · Motion

Slow, soft, and informative.

Three patterns recur. Every animation is gated behind prefers-reduced-motion: reduce.

LIVE

Live pulse

1.4–1.6s opacity oscillation, optional 0.9–1.1 scale.

↑ HOVER ME

Lift on hover

-1 to -3 px translateY, 180-250 ms ease, deepen shadow.

Reveal on scroll

opacity 0→1, translateY 18px→0, 700 ms cubic-bezier.

Reduced motion gate

motion-gate.css 
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
  /* Plus disable atmosphere drift, browser tilt, sheen, spotlight */
}
12 · Minimum identity

Six things you can't drop.

Skip any of these and the brand starts to feel like something else. Get all six and a reader will recognize it as Vigil before they read a single word.

01

The mark

A cube-stack or derivative in the same palette, drop-shadowed in cyan.

02

The atmosphere

Fixed multi-radial glow + masked grid behind everything.

03

Hero chrome recipe

Header gradient + grid overlay + corner glows on every dark hero element.

04

Type triumvirate

IBM Plex Sans / Lato / IBM Plex Mono, used by role.

05

Accents as LEDs

Saturated colors only on text, icons, strokes — never as backgrounds.

06

Tabular figures

Anywhere a number can change in place. No exceptions.
